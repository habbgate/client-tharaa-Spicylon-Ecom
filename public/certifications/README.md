# Certification artwork

ISO 22000:2018, GMP and HACCP badge images were generated using the built-in image_gen tool to follow the blue, green and gold visual direction in Spicylon’s promotional reference.

These are custom informational graphics, not official certification-body marks or certificate documents. The certifications displayed are based on the information provided by Spicylon.

Assets: iso-22000.png, gmp.png, haccp.png. Exact prompts are recorded in generation-prompts.json.

The original badge-check.svg decorative icon remains available, with its Lucide license in LICENSE.txt, but is no longer used by the certification component.
